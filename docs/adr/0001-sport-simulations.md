# Six independent sport simulations

Status: accepted.

Retain the six-event computer lineup rather than the Lynx's four. Each sport owns a distinct simulation; a small common lifecycle covers time, scoring feedback, and results. This costs more code than a universal obstacle template, but the recognizability resides in momentum, camera, and input rhythm. Use a fixed 1/60-second step for reproducibility. Short rounds and published medal targets replace multiplayer rankings, keeping a full meet practical in one browser session.
